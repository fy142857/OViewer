# 悬浮返回按钮（Issue #90）

## 使用方式

默认开启，包括新安装及从旧版本升级。按钮在应用内各页面和全屏阅读器中显示，不需要系统悬浮窗权限，也不会出现在外部浏览器或系统权限窗口上。

- 点击：键盘打开时先收起键盘；没有键盘时关闭当前可返回的弹层、侧栏或返回上一页。保留页面原有的返回限制，首页根页面不会退出应用。
- 拖动：在可用区域自由移动，松手后停留原位，不吸附边缘，也不触发返回。所有页面共用位置，重启后恢复。
- 设置 → 外观：开关“悬浮返回按钮”；大小滑杆在 32–72 逻辑像素之间调整，默认 48。调节时实时预览，松手后保存；关闭时保留上次大小和位置。
- 按钮采用半透明背景和返回箭头，支持深浅主题及中英文辅助功能标签；即使视觉尺寸较小，触控区域也至少为 48。按钮区域以外的点击、滚动和缩放正常交给页面。

默认位置在安全区域右侧、纵向约 70%，边缘留 12。位置按未弹出键盘的安全区域归一化保存；旋转、系统栏和大小变化后重新计算边界。键盘避让只临时移动按钮，收起键盘后恢复原位置；主动拖动则保存新的位置。

## 实现与兼容

全局宿主通过 `MaterialApp.builder` 叠放在现有 Navigator 上方，复用原有 navigatorKey，不改变页面内容的 MediaQuery、阅读器尺寸、路由动画或导航栈。拖动的逐帧状态只在悬浮层内更新；滑杆使用独立的临时预览，不逐帧更新 SettingsBloc 或写入磁盘。

返回调用 `NavigatorState.maybePop()`，保留侧栏局部历史以及 `WillPopScope` 等返回拦截。原生网页沿用应用页面的返回逻辑，不新增网页历史后退；键盘通过 `oviewer/floating_back` 的 `hideKeyboard` 方法收起，Android 仅操作当前 Activity，iOS 对当前应用窗口结束编辑，不模拟系统返回键。

`FloatingBackSettings` 保存 enabled、size、x、y，经 SettingsBloc → SettingsRepository → LocalStorage 写入一个 `floating_back` 偏好项。更新按字段合并、串行保存，避免位置、大小和开关互相覆盖；保存失败保留最近一次成功配置并提示重试。缺失或无效字段使用默认值，不需要数据库迁移。未改动阅读位置、预加载、图片缓存或网络调度实现。

## 验证记录

专项用例覆盖配置默认值、恢复、损坏数据、串行更新、保存失败及重试；覆盖返回拦截、侧栏与弹层、首页不退出、键盘优先、自由拖动、位置记忆、尺寸预览、禁用开关、安全区域和旋转。

六种全屏离线阅读组合覆盖单/双页及三种阅读方向，确认按钮可见、拖动不改变阅读进度、点击返回后阅读器正确销毁。既有 64 项 `reader_prefetch_slow` 接入悬浮层，保留原有断言，并检查拖动及更新悬浮配置不会重建 ReaderBloc、改变预读目标或增加图片请求。

2026-11-12 验证结果（Flutter 3.16.0）：

- 完整 Flutter 套件覆盖 1,449 项，初次执行为 1,446 通过、3 失败。已修复触摸取消仍触发保存的问题，并补齐两个启动用例的新增配置模拟值；受影响的控件、应用入口、离线阅读及全部预读组合随后复验 **111 项通过**，其余未受修补影响的通过结果复用。真机发现辅助功能节点边界被合并后，补充独立节点与边界断言，最终控件 **10 项通过**；没有排除未解决失败后宣称全量通过。
- 64 项 `reader_prefetch_slow` 均在接入悬浮层后通过，覆盖按钮拖动及配置改变不影响阅读进度、ReaderBloc 实例、预读目标与请求数量。另有六种全屏离线阅读组合通过。日志：`build/issue90-all-tests.log`、`build/issue90-final-ui-regression.log`、`build/issue90-host-acceptance.log`。
- Android 键盘桥接在 API 28、35 的 2 项原生测试通过，确认真实输入管理器的键盘显示状态变为隐藏，Activity 不结束。静态分析 190 项诊断，无新增错误或警告。临时 SDK 锁文件变化已恢复，不提交依赖升级。
- 华为 VOG-AL10（`APH0219605010506`）已用普通 `lib/main.dart` 的 Debug 包安装并启动最终代码，`essential_init=ok`，未锁屏。实际操作确认：默认开启；拖动后页面不返回且位置写入偏好；大小从 48 调至 64 后同步放大并保存；关闭后按钮消失，重开保持配置；强制停止并重新启动后位置恢复；搜索页第一次点击仅收起键盘、第二次回首页，首页再点击不退出。辅助功能树中按钮为独立 144×144 物理像素节点，对应 48 逻辑像素，未覆盖整屏。
- 真机验收结束保留开启状态和 48 大小，按钮放回右侧约 70% 高度，应用停留设置页。截图在 `build/issue90-settings.png`，安装日志在 `build/issue90-device-final.log`。没有输入账号、退出登录或修改其他设置。
