# 离线下载暂停恢复验证（Issue #59）

## 场景与实现

覆盖同次运行中的暂停恢复，以及结束应用进程后的恢复。下文保留原暂停恢复对比，并增加真实进程重启验收。原对比基线为 `ede1593` 中的下载协调器，首次修复为 `4b8f1f6`；双方使用相同的下载页面、数据库、图片文件和受控网络。

- 目录、下载进度、文件路径和摘要继续保存在数据库。恢复时验证完整目录与站点/gid/token 一致后复用，重新读取最新进度；进程重启不再强制重新获取目录。
- 校验成功后，文件记录同时保存校验版本、微秒精度的修改时间和文件变更时间，与已有路径、长度和摘要关联。启动和恢复时先检查文件元信息；未变化时不重新读取内容计算摘要。变化或缺失的文件重新检查并补下载，阅读器仍校验实际内容。
- 已知未完成页先进入下载，已有文件检查同时进行。完成状态必须等待检查结束及损坏页补下载，不能只因为下载队列暂时为空就标记完成。
- 目录不完整或被标记需要刷新时重新准备；来源/会话变化对涉及的任务持久标记目录刷新。复用目录后遇到图片页 404/410 或页面解析失败，最多自动刷新一次目录，持续失败则停止；鉴权和配额错误仍按原策略暂停。删除清除记录，单页修复使对应校验记录失效。
- 点击后立即显示恢复状态，禁止重复点击，允许再次暂停或删除。连续状态通知合并为一次列表刷新。
- 主动取消响应流和丢弃错误响应体；旧写入及清理完成后才释放并发名额。离线图片文件格式不变；数据库从 schema 3 升级到 4，仅增加校验元信息及目录刷新标记。旧记录默认没有可信校验记录，首次完整校验后补齐，之后重启不再重复摘要读取。

## 同次运行的真机方法（4b8f1f6）

Huawei VOG-AL10，Android 10，Flutter 3.16.0 Profile，独立包名 `com.oviewer.oviewer.offline_test`。正式版与日常 Debug 版不参与测试。

入口：`test_driver/offline_resume_benchmark.dart`。使用真实下载协调器、SQLite、文件存储、DownloadBloc 和 DownloadScreen；模拟触摸“继续下载”。网络只提供固定目录和可取消的图片流，目录每页固定延迟 10ms，每页目录包含 40 张图片。

两组各预置 10 / 1000 张有效 PNG，每张 256 KiB，另留一页未完成。每组预热两次且等待文件检查完成，再采集 20 次暂停恢复。P95 采用排序后第 19 个样本。

- 界面反馈：触摸至显示恢复或后续活动状态的首个完成帧。
- 恢复请求：触摸至首次调用剩余图片页请求；不包含服务器响应和图片传输耗时。
- 基线仅替换为历史协调器，保持当前界面和同一夹具，因此不将基线界面耗时当作旧版界面的测量。
- 公网吞吐未测量；这些数据用于验收恢复调度，不代表 EH/EX 服务器或代理的实际下载速度。

## 真实进程重启验收

入口：`test_driver/offline_restart_benchmark.dart`。同一台 Huawei VOG-AL10 / Android 10 / Flutter 3.16.0 Profile，仍使用独立包名。首次启动创建真实磁盘 SQLite 和两本漫画，分别已有 10、1000 页，每页 256 KiB，各留一页未完成；随后实际结束进程并重新启动 10 次，每次核对不同 PID。

每次启动检查共 1010 个已完成文件，之后通过真实下载页面分别继续两本漫画。20 个恢复样本全部满足：启动摘要读取 0、恢复摘要读取 0、目录网络请求 0。没有用保留旧对象或仅重新创建协调器代替真实进程重启。

| 场景 | 中位数 | P95 / 最大值 |
| --- | --- | --- |
| 离线仓库启动检查（两本共 1010 页） | 204.434 ms | 468.901 ms |
| 重启后继续，已有 10 页：界面反馈 | 33.259 ms | 51.179 ms |
| 重启后继续，已有 10 页：首次剩余页请求 | 12.697 ms | 27.298 ms |
| 重启后继续，已有 1000 页：界面反馈 | 47.811 ms | 78.829 ms |
| 重启后继续，已有 1000 页：首次剩余页请求 | 32.021 ms | 50.730 ms |

每组 10 次，P95 采用 nearest-rank，因此等于最大值。启动检查时间仅指离线仓库初始化，包含数据库打开/迁移检查、文件快速校验和残留文件清理，不是整个应用启动时间。恢复请求指标从点击继续开始，不含服务器响应和图片传输时间。

校验记录不是永久的内容正确性证明。大小或时间变化、未知校验版本会重新计算摘要；阅读时始终检查真实内容。数据库升级保留原文件、进度和阅读位置，旧数据只需完成首次校验建档。请求、并发名额、取消状态等仍仅存在内存，启动不会自行下载。

## 回归与证据

- 842 项 Flutter 测试通过；52 项版本脚本测试通过；静态分析无新增错误或警告。
- 新增真实磁盘数据库关闭/重开测试：有效目录复用、正常文件免重复摘要读取、缺失/长度变化/同长度损坏/仅修改时间变化、未知校验版本升级、schema 3→4 迁移及数据保留。
- 覆盖失效页面一次目录刷新、持续失效停止、刷新要求跨重启保留、EH/EX 隔离、旧校验结果不能覆盖新文件、取消的校验不能持久化成功记录、单页修复及删除清理。
- 保留暂停/继续、并发限制、过期写入拦截、先下载后检查的完成门槛、iOS 前后台恢复，以及中英文界面交互测试。
- 本次真实重启记录：`build/issue59-restart-phone.log`、`build/issue59-restart-validation.json`；完整回归：`build/issue59-restart-final-full-tests.log`、`build/issue59-restart-analysis.log`、`build/issue59-restart-version-tests.log`。
- 首次完整回归出现一次已有图片缓存测试的 Windows 临时目录删除失败；该测试单独复核通过，随后完整 842 项重跑通过。测试逻辑未因该清理失败而放宽。
- 重启验收首次日志连接中断时，确认原进程仍在运行并完成准备，只重新连接日志；随后完成 10 次真实进程重启。

## 复测与交付

仅在独立测试包运行该入口，入口本身会校验包名。Profile 构建使用本地 Gradle 初始化脚本将 `profile.applicationIdSuffix` 设置为 `.offline_test`，显示名称设为 `OViewer Offline Test`，然后通过 `-Ptarget=<入口绝对路径>` 构建。不得使用正式版包名。

原暂停恢复基线从上述提交读取协调器源码，仅补充当前界面所需的 `resumingIds` 空集合接口，通过 `runResumeBenchmark` 工厂参数注入。重启入口首次输出 `SEEDED`，随后每次真正结束进程并重启，收集 10 个 `COMPLETE` 标记和每轮两条样本。日志逐行刷新，不用截断日志统计。

代码推送至 `dev`，不修改构建产物、签名或版本号，不监听 Actions，不自动正式发布。独立测试应用已卸载；正式版与 Debug 版的版本号、首次安装时间、最近更新时间核对一致，未被覆盖。
