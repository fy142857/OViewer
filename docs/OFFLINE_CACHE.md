# 离线缓存

## 使用

详情页的下载按钮会先显示漫画标题、页数及 EH/EX 来源，确认后进入侧栏“下载”队列。来源取自详情请求，不随后来切换的站点改变。继续下载时需使用原来源站点；无法确定来源的旧任务先选择来源并验证目录。

设置中的“离线缓存”分组独立显示文件占用，并提供两个设置：同时下载漫画数为 1–3 本，默认 2 本；全局图片并行数为 1–6 张，默认 4 张。图片额度由全部活动漫画共享。调低并发允许在途请求收尾，之后按新上限运行；设置保存失败不改变调度配置。

下载完成后，从详情或历史进入阅读器会优先使用对应来源的本地书籍。下载页也可打开尚未完成任务中的有效页面，缺失页显示“尚未缓存”。“重新读取”只读本地文件；“修复缓存（联网）”由用户主动加入补下队列。完整缓存后来出现损坏时仍打开本地书籍并提示修复，不偷偷切换到在线读取。

离线图片、目录、封面及阅读进度持久化保存。左右翻页、反向阅读、纵向阅读、动图和保存图片使用现有阅读器。退出登录、切换站点、清理普通图片缓存不删除离线文件；手动删除任务会一并清理文件。删除失败保留记录供重试。

## 后台与恢复

Android 使用单一 FlutterEngine 和 `dataSync` 前台服务，在后台保留同一个调度器、数据库和认证上下文。下载通知显示汇总进度并提供暂停；活动结束后停止服务并释放唤醒锁。通知权限拒绝不弹额外提示、不阻止下载，也不反复请求权限。

iOS 进入后台暂停，回到前台只恢复因后台暂停的任务。Android/iOS 进程结束后都保留有效页面，下次打开不自动联网续传，需要用户点击继续。Android 系统强制停止、系统后台时限或厂商电池策略可能中断服务，不提供强杀或重启后自动下载保证。

## 存储与边界

- 数据库 schema 3 新增离线漫画和页面表，历史记录增加来源字段；旧任务保持可迁移，不相信旧的完成标记。
- `(source, gid, token)` 派生独立目录标识。`Documents/offline`（Android 为应用 Flutter 私有目录下 `offline`）不与图片缓存混用，不参与图片缓存配额及云备份。
- 二进制响应写入唯一 `.part`，检查响应长度、格式及可解码性，计算 SHA-256 后原子改名，最后登记页面完成；登记前中断留下的文件在启动恢复时清理。
- 每页最多三次尝试，目录并发上限为 1；暂停、删除和会话变化取消请求，过期任务不能登记页面。失败页不计入进度，只有全部页面有效才完成。
- 普通离线列表与本地读取不访问画廊网络；只有启动、继续、确认旧来源或主动修复才会下载。站点切换与登录变化会暂停原任务，不跨来源发送请求。

## 验证入口

```text
flutter test --no-pub test/offline
flutter test --no-pub
python -m scripts.versioning.analyze
python -m unittest discover -s scripts/tests -v
android/gradlew :app:testDebugUnitTest
```

Windows 本机 Gradle 如遇 `Unable to establish loopback connection`，使用候选 Android 工作流的 `offline_emulator_apk=true` 构建隔离测试包；该包的应用 ID 为 `com.oviewer.oviewer.offline_test`，不覆盖原应用，不能作为正式发布产物。

本机运行 `python -m scripts.offline_fixture_server`，再对测试模拟器执行 `adb -s <模拟器序列号> reverse tcp:8765 tcp:8765`。测试应用通过 `127.0.0.1:8765` 代理及 ADB 转发访问 `10.0.2.2:8765` 样例地址，获取目录和 PNG/JPEG/GIF/WebP，避免依赖宿主机 NAT 回环访问。测试入口 `test_driver/offline_validation.dart` 使用生产 UI、存储、调度和原生服务，仅把 EH/EX 的 HTML/API 请求映射到此服务器。普通发布入口不接受该映射，也不会设置测试代理。

`/control?delay=2` 设置单页响应延迟；`/control?enabled=0` 让后续请求失败；`/control?reset=1` 清除请求统计；`/stats` 返回请求路径与图片请求峰值。验收需要记录后台/锁屏下载、暂停及恢复、退出进程、断网后本地阅读、来源隔离、设置变化和清缓存保留下载等证据。
