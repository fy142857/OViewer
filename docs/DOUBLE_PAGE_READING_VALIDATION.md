# 双页阅读验收（Issue #70）

日期：2026-10-25。此记录对应开发分支实现，不代表已正式发布。

## 行为约定

- 默认单页；双页固定按 1–2、3–4 配对，末尾落单页单独显示。宽图不改变配对。
- 三种阅读方向均支持双页，横竖屏保持所选布局；从右到左阅读时小页码在右，其余方向小页码在左。
- 两页整体缩放，每页分别加载、重试、修复和保存；长按操作触碰的原始页，不导出拼接图片。
- 页面布局与阅读方向由全局设置保存；阅读器设置从右上角按钮处弹出菜单，提供两个选择器。横屏垂直阅读时额外显示对齐选择器，单页、双页均支持按宽度或阅读区域高度适配，默认按宽度并保存偏好。
- 历史、滑块和缩略图继续使用原始页码。明确跳到组合中的第二页后，切回单页仍定位该页；自然翻页使用新组合的起始页记录进度。

## 宽度对齐与次级菜单定位补充（2026-10-25）

- 横屏垂直双页在按宽度对齐时，以整组较高图片决定行高，两张图片沿该行的水平中线居中；竖屏仍顶部对齐，按高度适配和横向双页布局保持原有规则。
- 次级菜单以点击的选择器顶部为定位起点，选项从第一项向下排列，不再按当前选中项重新居中；下方高度不足时限制菜单高度并允许内部滚动。
- 覆盖中英文、大字体、已选末项、较矮横屏以及同组图片高低不同的布局断言，验证选择结果持久化及父菜单保持打开。相关记录：`build/reader-submenu-position-tests.log`、`build/reader-submenu-tests.log`。完整回归 972 项、版本脚本 52 项通过，静态分析无新增错误或警告；正常 Debug 构建通过并已覆盖安装到手机，保留原数据。本轮菜单定位及图片对齐依据 widget 渲染／交互测试验收。
