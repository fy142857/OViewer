# 双页阅读验收（Issue #70）

日期：2026-10-25。此记录对应开发分支实现，不代表已正式发布。

## 行为约定

- 默认单页；双页固定按 1–2、3–4 配对，末尾落单页单独显示。宽图不改变配对。
- 三种阅读方向均支持双页，横竖屏保持所选布局；从右到左阅读时小页码在右，其余方向小页码在左。
- 两页整体缩放，每页分别加载、重试、修复和保存；长按操作触碰的原始页，不导出拼接图片。
- 页面布局与阅读方向由全局设置保存；阅读器设置面板提供两个选择器。
- 历史、滑块和缩略图继续使用原始页码。明确跳到组合中的第二页后，切回单页仍定位该页；自然翻页使用新组合的起始页记录进度。

## Android 真机

Huawei VOG-AL10 / Android 10 使用独立临时包及五张本机生成的带页码示意图片，其中包含横向宽图及不同高度图片；不读取用户账号或漫画内容。

- 实际查看竖屏、横屏双页截图，确认两页完整包含，宽图仍与相邻页固定配对。
- 通过两个选择器切换布局和方向，确认双页中的第 2 页切回单页后仍为第 2 页。
- 从右到左时，左侧长按菜单为第 2 页，右侧为第 1 页；右划后进入第 3–4 页。
- 纵向模式每行左小右大，图片顶部对齐；滚动到奇数末页时显示第 5 页和 `5 / 5`。
- 检查临时包 SharedPreferences，双页布局及纵向阅读设置均已写入；临时包日志无未处理异常。
- 证据：`build/issue70/device-result.json` 与同目录示意截图。双指缩放通过 widget 手势测试验证，未声称在真机注入多指手势。
