# EH/EX 切站验证（#54）

## 行为与边界

切换先更新 `pendingSite`，设置页立即显示目标站点并短暂禁用开关；`useExHentai` 和全局站点仍表示已生效的站点。EX Cookie 准备和设置保存成功后才提交切换；准备失败、保存失败或登录会话改变时回退，允许重试。离开设置页不取消应用级切换。

切站不再等待图片磁盘缓存逐项删除。在线封面、普通/精灵缩略图、阅读器图片使用站点和持久化随机会话标识构成的缓存键，登录凭据替换或退出登录时更换标识。请求有效期另含站点切换代数，因此切回同一站点可以复用已完成缓存，但不会恢复旧请求。旧的无作用域图片不再回退读取，由原有容量/过期管理清理；手动清空仍删除全部作用域。两站共用总容量限制，离线文件及数据库结构不变。
