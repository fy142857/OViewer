# 收藏搜索与独立入口

## 使用方式

首页收藏和侧栏收藏顶部提供灰色搜索框。点击进入搜索输入页，带入当前关键词，提供与普通搜索共用的历史和标签联想；提交后返回原收藏列表，取消不改变原列表。输入页不先执行全站搜索，隐藏键盘保留草稿及已显示的联想。

每个入口独立保存关键词、Favorite 分组、结果、分页和列表/卡片滚动位置。三横杠选择“显示全部”或 Favorite 0–9，切换分组保留本入口关键词，取消旧请求、重置分页和滚动位置并重新查询。另一入口不改变条件，也不新增或取消请求。搜索框右侧 × 清除当前入口关键词，恢复其当前分组列表；不删除搜索历史。

同一次运行中从详情返回、关闭后重开侧栏或切换首页标签，均保留各自状态。重启仅恢复各自分组，关键词清空；历史记录仍保留。详情页“收藏分组偏好”继续独立。

## 查询与分页

所有请求均限定在当前 EH/EX 站点的 `favorites.php`。使用 `f_search`、标题/标签搜索参数和选中的 `favcat`；全部模式不带 `favcat`，不遍历十组拼接，也不靠本地已加载数据筛选。

普通搜索和收藏搜索共用查询展开与合并工具：中文标签归一化、标题备选、普通关键词补充上传者查询、按 gid 去重及多路分页。纯数字增加收藏范围内的 `gid:` 分支；完整画廊链接转换为 `gid:`，不直接跳转未收藏画廊。按站点规则，旧 GID 可匹配更新链中的最新画廊。

多路分页游标包含站点、原始查询、分组、各路下一页及已见 gid；与其他查询条件不匹配时拒绝使用。每个入口独立持有游标。下一页只接受同站点收藏页，解析查询式相对链接时保留当前关键词和分组。重复页有下一页时继续加载，循环游标报错；失败不消耗游标或丢弃已有结果。

参考：[收藏搜索](https://ehwiki.org/wiki/Favorites)、[收藏查询参数](https://ehwiki.org/wiki/Gallery_Search_Engine)、[GID 等查询语法](https://ehwiki.org/wiki/searches)。

## 状态与存储

应用级 `FavoritesBloc` 持有首页状态及侧栏状态容器，通过 `FavoritesEntry` 定位；两个容器各自管理请求代次、取消令牌、错误、分页去重及滚动存储，侧栏退出路由后不销毁状态。路由可见性与首页当前标签共同决定是否自动刷新。

登录会话集中同步，站点变化保留两入口各自的条件、使旧数据失效；可见入口立即加载，隐藏入口下次进入时加载。退出登录或换账号清空关键词和结果，保留分组界面偏好。真实云端收藏增删会刷新可见入口，取消隐藏入口旧请求并标记待刷新，不将某一入口的条件复制给另一入口。

`favorite_category_home` 和 `favorite_category_sidebar` 分别保存 -1 或 0–9。旧 `favorite_category` 为缺失的新键提供一次初始值；已有新键不被覆盖，非法值回退到全部。两个新键都落盘后才删除旧键；平台返回失败或抛出异常时重新读取真实存储，避免把 SharedPreferences 的乐观缓存当作迁移成功。重试只补齐缺失的新键。保存期间阻止当前入口重复切组，失败保留原选择并提示。

关键词、结果、分页和滚动位置不落盘。不新增数据库表，不影响详情页的 `favorite_destination`。搜索历史沿用普通搜索的存储与增删接口，只保存用户提交的原始文本；历史保存失败不阻断查询。

- 协议与状态测试覆盖 EH/EX 全部及十个分组、上传者、数字和链接、标题备选、查询游标绑定、重复页、失败重试、非法页面、入口隔离、旧响应丢弃、隐藏入口失效，以及迁移部分失败与异常恢复。
- 页面测试覆盖中英文、深色主题、输入/取消/清除、共享历史删除、隐藏键盘保留联想、错误时清除入口、独立分组，以及列表/卡片滚动位置跨路由恢复。
- Android Huawei VOG-AL10 通过应用自身会话验证了 EH/EX 查询、无匹配结果、非零空分组、保留关键词切组、EX 搜索后续分页、两个入口条件隔离，以及重启分别恢复分组并清空关键词。未增加或删除云端收藏，没有导出 Cookie 或完整私有响应。
- iOS 没有可用真机，真机验证不作完成声明；构建及自动化结果以本候选 CI 为准。

本地最终完整回归通过 **630 项测试**，静态检查无新增错误或警告，Android Profile 构建成功。最终包完成覆盖安装及启动检查后恢复测试前原安装包，SHA-256 一致；EX 模式和全部分组已恢复，仅本次新增的三条测试搜索历史已删除。
