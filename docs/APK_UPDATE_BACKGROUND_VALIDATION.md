# Issue #60：APK 后台更新验证记录

## 验收约定

- Android 切后台、锁屏、隐藏窗口时继续下载；iOS 保留发布页跳转。
- 中断保留有效断点，下次打开应用由用户继续；取消删除下载文件。
- 全程停留更新窗口时自动进入安装；一旦隐藏或切后台，本次下载必须由完成通知或“立即安装”继续。
- 更新和离线缓存使用独立通知，共用引擎时分别登记占用，彼此结束不影响另一项。
- 不绕过强制停止和厂商杀进程；系统清除缓存时重新下载。通知被拒时不反复弹窗。

## 实现

- 新增 Android `dataSync` 更新服务、通知渠道和 Application 级通信桥接；下载启动等待前台服务确认，完成、失败和取消时释放任务占用。
- 安装包检查移至 Application Context；安装器和安装授权设置仍要求前台 Activity。
- `package.part` 与带版本标识的 `resume.json` 保存断点；完整文件继续使用 `package.apk`、`metadata.json`，无数据库迁移。
- 保留同一目标的 SHA-256、大小、构建号、地址、证书及有效 ETag/Last-Modified；续传校验 Content-Range，200 回退重下，416 至多重下一次，完成后校验全文件。
- 更新 HTTP 客户端仅在既有可信 HTTPS 目标间保留 Range/If-Range，不转发认证信息，保留严格 TLS 和应用代理。
- 窗口显隐参与安装决策，通知携带任务标识及本次通知标识，旧通知不能触发新目标安装。

## 设备验收

### Huawei VOG-AL10 / Android 10

- 使用独立测试包下载 24 MiB 合成文件，限速约 64 KiB/s；不读取账号，不将合成文件交给系统安装器。
- 更新服务实际为前台服务，通知 ID 7702。隐藏窗口、切后台并锁屏后文件持续增长：锁屏开始约 1.9 MiB，259 秒采样约 18.1 MiB，解锁前已完整下载；锁屏观察时长超过五分钟。
- 完成通知显示“Download complete. Tap to install”，解锁返回后状态为 ready。该轮手机合成安装器的日志不可用，不以缺失日志宣称已测真实安装；真实安装见模拟器记录。
- 在 1 MiB 处主动断流，保留 package.part/resume.json；结束进程并重启后显示“继续下载”，没有自动下载。
- 点击继续后服务端收到 `Range: bytes=1048576-`；下载完成的 SHA-256 与原始合成文件一致：`206320acc7e9ae70b2e614a2a98ef92a9aa6b3b21cb0aa378c5c16c1a4b0e993`。
- 证据：`build/issue60-lock-test.json` 及本次工具执行记录。

### 隔离模拟器 / API 36

- 真实签名 APK 验证：基线 1.10.2（109）通过应用内下载和未放宽的生产签名检查，进入系统安装器并升级至 1.10.2（110）；升级后正常 main 应用界面启动成功。构建号覆盖仅用于模拟器，不写入版本文件或发布台账。
- 拒绝通知权限后仍完成后台下载；返回应用保持 ready，没有自动进入安装器。
- 允许通知后显示完成通知；点击通知才进入安装授权说明，允许安装来源并返回后打开系统安装器。
- 独立并行测试使用真实离线仓库、调度器、文件解码及 300 张合成图片：离线通知 7701 与更新通知 7702 同时存在。更新完成或取消后离线任务继续；暂停离线任务后更新任务继续；离线图片最终完成 300/300。
- 通知栏取消 APK 下载后，更新服务停止，updates 目录为空；没有新增安装请求。
- 将测试模拟器 dataSync 限额临时改为 10 秒后，系统实际触发超时：更新服务停止，保留 720,896 字节断点，界面提示系统已暂停。恢复设置后可继续完成。
- 通过返回键关闭根 Activity 后，桌面成为前台，APK 服务仍运行并继续写入，最终哈希正确；服务结束后 Activity 已不存在。完成通知重新打开测试应用、恢复就绪包并处理本次点击。
- 连续停留更新窗口时，测试安装请求计数为 1；隐藏或切后台后的流程由手动操作继续。
- 证据：`build/issue60-real-install.json`、`build/issue60-parallel-result.json`、`build/issue60-timeout-result.json`。
- 未使用独立 API 33/35 真机或模拟器镜像；相应版本以原生回归覆盖，并在 API 36 实测 Android 13 起的通知权限及 Android 15 起的 dataSync 限制，不将这些结果表述为独立 API 33/35 设备验收。
