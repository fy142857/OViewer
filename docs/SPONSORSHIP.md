# 作者赞助入口

## 展示与资源

设置 → 关于 → 检查更新下方展示双列赞助码，微信在左、支付宝在右。两个展示区域采用相同宽度和 1:1 比例，白色背景，图片等比完整显示；不裁剪、重绘或更改赞助码。窄屏及放大字体下说明文字可换行。

微信入口使用绿色“保存图片跳转微信”，支付宝入口使用蓝色“保存图片跳转支付宝”。下方中文配文固定为“制作不易，您的支持是我开发的最大动力 (:3 」∠ )”；英文界面提供对应翻译。深色主题调整文字颜色以保持可读性。

用户提供的第二张 PNG 为微信赞赏码，第一张 JPEG 解码域名为 `qr.alipay.com`，用作支付宝收款码。文件分别保存在 `assets/sponsors/wechat.png`、`assets/sponsors/alipay.jpg`，与原附件逐字节一致，同时用于 Flutter 内置资源及 README。README 顶部按相同左右顺序展示原图。

## 行为与平台

一次点击独立启动“保存图片”和“打开应用”两个异步任务，二者均不等待对方完成，失败各自处理。微信和支付宝按钮各自防止重复点击，不共用忙碌状态。保存成功由原生层触发 Android Toast 或 iOS 本地通知，不再显示应用内成功 Snackbar。失败及 iOS 通知未开启说明仍使用应用内提示，在后台发生时延后至返回前台显示。

保存的是原始图片，不是缩小后的屏幕截图。Dart 将资源写入单次操作专用临时目录，经原生通道存入系统相册，完成或失败后仅清理该临时目录。两个赞助码可并发保存，各自独立返回结果；阅读器原有单次保存行为不变。

- Android：Android 10 及以上通过 MediaStore 写入 Pictures/OViewer，无需读取相册权限；Android 6–9 使用现有写入权限。并发请求共用一次系统授权询问，授权结果分别完成各任务。旧版使用媒体扫描，使图片出现在相册中。
- Android 唤起：仅允许微信 `com.tencent.mm`、支付宝 `com.eg.android.AlipayGphone` 的启动入口，声明对应 package visibility，不接受任意包名或任意外部链接。
- iOS：复用 Photos 的添加图片能力，iOS 14 及以上使用 add-only 授权，保留 iOS 12/13 的既有兼容流程；权限说明同时覆盖页面图片与赞助码。通过固定 `weixin://`、`alipays://` 打开应用，并声明查询白名单。

单纯打开支付应用，不创建订单、自动扫码、确认付款或读取支付结果。应用可能恢复其上次页面，不能保证每次停留于首页。系统权限交互由操作系统控制；保存被拒绝不阻止打开应用，未安装应用也不阻止图片保存。

## 保存成功提示

仅赞助码成功提示使用 Android 原生短 Toast / iOS 通知中心，阅读器图片保存提示保持原样。提示由原生图片保存成功的回调触发；保存失败不显示成功提示，提示异常不改变保存结果。

Android 使用标准文本 Toast，通常位于屏幕下方，不写入通知栏，不申请通知或悬浮窗权限。首次成功保存时清理旧版赞助通知渠道，不影响其他渠道。跳转到其他应用后的显示受设备系统策略影响，不承诺在所有系统及支付应用前台均可见。

iOS 保留本地通知授权及前台展示。通知授权、图片保存和跳转不互相等待；授权过程中已完成的保存暂存通知，授权通过后发出，拒绝后丢弃。未开启通知时说明保存及跳转仍可用，不回退为应用内保存成功提示。通知默认无声音，展示效果遵循系统设置。

## 华为后台 Toast 权限

2026-10-09 实测确认，该设备将 OViewer 的“后台弹窗”设为“禁止”时，系统拒绝跨应用 Toast；普通通知开关及标准 `TOAST_WINDOW` AppOps 为允许，仍不能替代该权限。

原生诊断确认 Toast 在主线程调用并正常返回，系统 `ToastInterrupt` 日志明确记录 `isAllowToShowToast:false, pkg:com.oviewer.oviewer`。核对本机系统服务实现发现，`HwNotificationManagerService.isAllowToShow` 在来源包名与顶层 Activity 包名不同时，额外通过 `HwAddViewHelper.addViewPermissionCheck`（类型 2）检查显示权限，不通过便在 Toast 入队前返回。这解释了应用前台可见、切换微信/支付宝或桌面后不可见，以及延迟提示仍无效的结果。

正常解决入口：系统应用信息 → OViewer → 其他权限 → 后台弹窗 → 允许。应由用户决定是否授权，应用不自动更改该权限。经用户明确授权开启后，使用不含临时诊断代码的正常 Toast 安装包复测，微信和支付宝前台均捕获到 `Surface shown=true`、`isOnScreen=true`，确认能够边跳转边提示。无需延迟跳转，也不增加通知栏提示或绕过系统权限。
