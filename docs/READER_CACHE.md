# 阅读器重进缓存

## 使用行为

在应用进程未关闭时，阅读器优先复用近期成功解码的静态图片，直接显示清晰画面。只有磁盘缓存时，按已保存的页面对应关系读取、解码文件，不先请求站点图片页面。磁盘缺失、过期或损坏时，重新获取图片地址后加载；不会直接请求快照中的过期地址。

本次不持久化重进快照，不增加离线阅读入口，不使用缩略图过渡，也不降低图片解码分辨率。重启应用后仍按原流程获取页面信息。磁盘解码、首次访问或缓存失效时仍可能短暂显示加载指示器。

## 缓存和内存

- `ReaderReentryCache` 最多保留 20 个画廊、合计 1,000 条成功页面映射，按画廊和页面的最近使用顺序淘汰。站点、gid、token 标识画廊；会话代次、画廊快照序号和页面修订号防止旧结果回写。
- 已解码静态图片最多 6 张，保留的像素估算占用加保存资源所需的编码字节合计不超过 64 MiB；优先保留各画廊当前页。超大图片保留磁盘映射，系统内存紧张时释放所有额外保留的图片引用。
- 图片通过独立引用保留，不保留旧会话的请求、取消令牌或解码器。动图只保留文件映射，每次进入重新创建解码器，持续播放后续帧。
- 磁盘写入失败时仍可显示图片和暂时复用内存，但记录不会宣称磁盘写入成功。页面显示期间的“保存”仍可使用编码字节。
- 沿用原有图片文件、内容缓存键、旧 URL 缓存兼容读取和有效期，不额外复制文件；读取不会延长磁盘有效期。

设置中的“图片缓存”总量为磁盘实际文件字节加本模块保留的图片内存估算，另列阅读器内存说明。该值不是应用全部内存或进程 PSS。原有容量上限仍仅约束磁盘文件，新增内存有独立的 64 MiB 上限。

## 失效与生命周期

退出阅读器仍取消所有未完成请求，并清除该会话的 Flutter 图片流；共享的成功图片引用继续保留。重进时同步恢复页码和已知页面，显式选择的页码优先；目录仅在访问未知页面或需要目录时补取。

“重新加载”使该页共享记录失效，沿用现有重新请求和备用来源逻辑。同一页的本地缓存未命中合并为一次新地址请求。新目录中的页数或页面 token 变化会移除不匹配映射。

清除图片缓存同时清除重进快照和保留图片，并拒绝清理前任务的迟到结果；文件写入及登记过程也检查清理代次。登录、退出、账号变化、EH/EX 切换和站点设置返回沿用阅读索引的失效入口。删除历史移除对应画廊快照，清空历史移除全部快照，内容警告确认规则保持原样。

## 验证记录（2026-10-07）

组件和单元测试覆盖三种阅读布局首帧无加载指示器、保存资源、磁盘回退及新地址请求去重、动图多帧播放、缓存过期、数量与内存预算、会话及历史失效、磁盘写入失败、清缓存期间迟到文件写入，以及中英文缓存统计。

Android 实测设备为 Huawei VOG-AL10，基线源码为 `2912888`（v1.5.0 后发布文档提交）。两版均使用 Flutter 3.13.9 的 Profile 包、同一签名、原有数据和同一画廊第 9 页，阅读模式为纵向连续滚动。没有卸载应用或清除用户缓存。基线源码副本放在忽略目录，没有建立 Git 工作树。

使用 `--dart-define=READER_DIAGNOSTICS=true` 开启相同的匿名计数，仅记录进入、首图所在帧回调、HTML/目录/图片文件请求计数；不记录网址、画廊内容或凭据。首图时间从阅读器初始化到资源准备后的帧结束回调，属于应用侧时序测量，不等同于摄像机测量的物理屏幕延迟。正式构建默认关闭此计数。

| 指标 | 基线 | 优化后 |
|---|---:|---:|
| 排除首次进入后的样本数 | 5 次重进 | 20 次重进 |
| 首图耗时中位数 | 786 ms | 22 ms |
| 首图耗时范围 | 734–1,130 ms | 18–37 ms |
| 每次图片页面请求 | 5 次 | 首次重进 2 次，其余 19 次 0 次 |
| 目录请求 / 图片文件请求 | 均为 0 | 均为 0 |
| 重进时进程 PSS 范围 | 326.1–363.1 MiB | 292.4–352.1 MiB |
| 最后 5 次 PSS 中位数 | 346.8 MiB | 297.2 MiB |

优化后的首次重进仍有尚未形成成功图片缓存的相邻页面请求；之后 19 次全部为零。样本未见内存随进出次数持续增长；PSS 包含运行时、图形和其他应用缓存，波动或较低数值不代表本模块能够降低所有设备的总内存。以上结果仅代表该设备、页面和测试条件。横向及反向阅读的首帧行为由组件测试覆盖。

最终完整回归通过 482 项测试，项目静态检查无新增错误或警告。测试完成后已恢复设备原安装包，安装后的 APK 与测试前备份 SHA-256 完全一致；未修改阅读模式或清除用户数据。
