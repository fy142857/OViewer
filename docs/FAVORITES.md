# 收藏分组与分页

## 使用方式

首页收藏标签和侧栏收藏页右下角提供三横杠按钮，使用与搜索页设置按钮相同的 `FloatingActionButton.small`。点击后可选择“显示全部”或 Favorite 0–9。两个入口共用选择和数据，重启后恢复上次分组；首次使用、缺失或非法偏好值均显示全部。

切换分组回到列表顶部；重复选择当前分组不重复加载。弹层可滚动至全部十一项，并标记当前选择。按钮和菜单为系统手势区预留最低留白，兼容部分未正确上报底部 inset 的 Android 设备。未登录显示登录提示，不显示筛选按钮。

首页保留列表/卡片布局、横向切页和下拉刷新；侧栏保留列表和左滑删除，同时增加滚动分页及失败重试。删除或新增收藏后刷新当前分组，不回到 Favorite 0。不管理或重命名网站收藏分类。

## 详情页收藏目标

详情页爱心按钮正上方新增三横杠按钮，可选择 Favorite 0–9；首次使用默认为 Favorite 0。菜单勾选当前目标，关闭菜单不改变选择。选择只保存偏好，点击空心爱心才将当前画廊收藏到所选分组；实心爱心仍用于取消收藏，选择新目标不会自动移动已有收藏。

目标分组以 `favorite_destination` 独立保存，EH/EX 共用，重启后恢复；不受首页和侧栏的 `favorite_category` 显示筛选影响。保存期间禁用这两个按钮，保存失败显示中英文提示并保留上次确认的目标。缺失、类型错误或超出 0–9 的历史值回退到 0；收藏请求也校验分组范围。

自动化验证覆盖中英文菜单、手机竖屏下按钮上下对齐、末项可访问、取消选择、保存失败、重新创建本地存储后恢复，以及 EH/EX 十个分组的详情页收藏请求和取消收藏。本次完整回归通过 569 项测试，静态检查无新增错误或警告；本次详情页改动未进行真机验证。

## 数据与状态

两个入口统一使用应用级 `FavoritesBloc` 和 `FavoritesRepository`。全部请求不限定 `favcat`，单组明确使用 `favcat=0…9`，不分别拉取十组拼接。收藏页使用站点返回的内容，不再套用首页最新/热门的本地隐藏标签过滤。

原实现没有把云端请求写死为 Favorite 0，但侧栏没有接入加载更多，两个入口的数据路径也不一致。现在按实际下一页链接加载；查询式链接相对于 `/favorites.php` 解析，保持站点与选中分组，不误跳到普通画廊列表。只有存在明确数字分页依据时才生成页码链接；终页不无限猜测下一页。

结果按 gid 去重；重复页有后续链接时继续读取，循环游标报告可重试错误。失败保留已有结果和原游标。局部页面、空分组不表示其他收藏已删除，不清空未访问分组的收藏标记。未知分组的本地确认缓存不再伪记为 Favorite 0，已有分组值予以保留；显示筛选始终以云端为准。

`favorite_category` 是全局界面偏好，-1 表示全部，0–9 表示单组，不新增数据库表。两个入口及 EH/EX 共用偏好；账号或站点变化会取消旧请求、重置列表和确认缓存。保存操作串行执行，最后一次选择生效；保存失败保留原选择并提示重试。

请求代次和取消令牌阻止旧分组、旧账号、旧站点响应回写。收藏增删同时校验登录会话，避免等待本地数据库期间切换账号后向新账号发送旧操作。关闭期间的异步保存不会重新启动请求。

## 验证

- 协议测试覆盖 EH/EX 的全部与十个单独分组、查询式/数字分页、终页、空分组、异常 HTML 和跨站链接拒绝。
- 状态测试覆盖共享选择、重启恢复、非法偏好、快速切换、迟到响应、账号/站点切换、去重分页、循环游标、失败重试、缓存清理失败恢复、删除后保持分组和关闭期间的请求保护。
- 界面测试覆盖两个入口共享状态、十一项菜单、与搜索页同款小号按钮的尺寸、底部安全区、未登录隐藏按钮，以及侧栏滚动加载和重试。首页卡片/列表及横向切页回归保持通过。
- 2026-10-08 在 Huawei VOG-AL10 上通过应用自身登录会话验证了非零分组的实际记录、空分组、切回全部、侧栏后续分页、两入口同步及重启恢复。没有增加或删除用户的云端收藏；验证数据仅保留分组和数量诊断，不保存 Cookie 或完整私有页面。
- 诊断开关 `--dart-define=FAVORITES_DIAGNOSTICS=true` 仅输出站点、分组、页次、数量和下一页标记，正式构建默认关闭。真实账号内容不纳入测试夹具或提交。

本地完整回归通过 560 项测试，静态检查无新增错误或警告。Android 设备验证后恢复原安装包并核对 SHA-256；筛选恢复为显示全部。iOS 未进行真机验证；构建与自动化检查结果以候选 CI 为准，不将 Android 实测当作 iOS 真机结果。
